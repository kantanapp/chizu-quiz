# 地図クイズ

**世界の国**と**日本の都道府県**をおぼえるクイズです。中学の地理の勉強用に作りました。
インストール不要、ブラウザだけで動きます（サーバーもビルドも不要）。

## 世界の国

| | |
|---|---|
| **出題** | 地図から / 国旗から / ミックス |
| **地域** | 世界ぜんぶ / アジア / ヨーロッパ / アフリカ / 北アメリカ / 南アメリカ / オセアニア |
| **レベル** | 基本 70か国 / 標準 152か国 / すべて 194か国（国連加盟国） |
| **国名の表記** | 日本語 / English / 日本語＋英語 |
| **問題数** | 10問 / 20問 / 30問 |

## 日本の都道府県

| | |
|---|---|
| **出題** | 地図から県名 / 漢字を書く / 県庁所在地 / ミックス |
| **地方** | 全国 / 北海道・東北 / 関東 / 中部 / 近畿 / 中国・四国 / 九州・沖縄 |
| **県名の表記** | 漢字 / ひらがな / 漢字＋よみ |
| **漢字のお手本** | なぞり書き（お手本あり）/ 書き取り（お手本なし） |
| **問題数** | 10問 / 20問 / 全部（47問） |

### 漢字を書く問題

地図でオレンジ色の県を見て、その名前を指で書きます。

- **書き順は採点しません。** どの画から書いてもかまいません。
- 書いた線を、まだ書かれていない画の「中心線」と照らし合わせ、いちばん近い画に当てはめます。
- **どの画にも当てはまらなかった線も消さずに残します。** 答えとは違う漢字を書いてみることも
  できます。書いたものはそのまま画面に残り、答え合わせのときに正解の形と見比べられます。
- 全部の画が書けたら自動で○。途中でも **「✓ 答える」** でその時点の答え合わせができます
  （足りなければ不正解にして、正解の形を重ねて出します）。
- ヒント（次の画を光らせる）と「↺ 消す」もあります。
- 判定のゆるさは、お手本があるときは厳しめ、お手本なしのときはゆるめに変えています。

判定のしきい値は `tools/` の検証で決めました。正しい画は 99%以上が通り、
でたらめな線は 9割方はじきます（`js/kanji.js` の `ACCEPT_GUIDED` / `ACCEPT_FREE`）。

## 共通のしくみ

- 地図は問題の国・県に合わせて自動でズームします。右下のボタンで
  **寄って見る → 地方（大州）全体 → 全体** と切り替えられ、ドラッグとピンチでも拡大縮小できます。
- 陸地は一色にして、区切りは境界線だけで見せています。色がついているのは正解だけです。
- 小さすぎて見えないときは、位置を示す丸い印がつきます。
- 終わったあとに、まちがえたところの一覧が出ます。「まちがいだけ復習」でもう一度出題できます。
- ベスト記録は設定ごとに端末に保存されます（サーバーには何も送りません）。
- 「📖 いちらんを見る」で、選んだ範囲の国・県を一覧・検索できます。

## iPhone でアプリのように使う

1. Safari で公開ページを開く
2. 下の共有ボタン → **「ホーム画面に追加」**
3. ホーム画面のアイコンから起動すると、Safari のバーが出ない全画面表示になります

一度開けばオフラインでも遊べます（Service Worker がアプリ本体をキャッシュします）。

## GitHub Pages で公開する

ビルドは不要です。リポジトリをそのまま置くだけで動きます。

1. GitHub のリポジトリ → **Settings → Pages**
2. **Source** を `Deploy from a branch`、ブランチを `main` / フォルダを `/ (root)` にする
3. 数十秒待つと `https://kantanapp.github.io/chizu-quiz/` で開けます

## ローカルで確認する

`index.html` をブラウザで開くだけで動きます（`file://` でも動作します。
オフライン用のキャッシュだけが無効になります）。

PWA の動作も含めて本番と同じ状態で見たいときは、簡易サーバーを立ててください。

## データを作り直す

`data/` と `icons/` は生成物です。作り直すときだけ Node.js が必要です。

```sh
cd tools
npm install
npm run build        # 下の3つをまとめて実行
```

個別に走らせるときは次のとおりです。

```sh
node build-data.mjs    # data/countries.js, data/geo.js
node build-japan.mjs   # data/prefectures.js, data/japan-geo.js, data/kanji.js
node make-icons.mjs    # icons/*.png
```

### 出題する国やレベルを変えたいとき

`tools/build-data.mjs` の上のほうにある次の 3 か所を書き換えて、`node build-data.mjs` を実行します。

- `LEVEL1` … 「基本」で出題する国（ISO の 2 文字コード）
- `LEVEL2_EXTRA` … 「標準」で追加する国
- `JA_OVERRIDE` / `EN_OVERRIDE` … 国名の表記を教科書に合わせて上書きする

都道府県名・よみ・県庁所在地は `tools/build-japan.mjs` の `PREFECTURES` の表にあります。

ファイルを更新したら、`sw.js` の先頭にある `CACHE` のバージョン
（`chizu-quiz-v4` → `chizu-quiz-v5` …）を上げてください。古いキャッシュが残らなくなります。

## 仕様のメモ

- 世界は**国連加盟の 194 か国**が対象です。地図データに形のない小さな島国
  （シンガポール、モルディブなど29か国）は、地図の問題には出ませんが国旗の問題には出ます。
- **国旗は絵文字**（🇯🇵 など）で表示します。iPhone・iPad・Mac はそのままきれいに出ます。
  国旗の絵文字を持たない環境（Windows など）では自動で [flagcdn.com](https://flagcdn.com) の画像に
  切り替わります（このときだけネット接続が必要です）。
- **都道府県に県旗・県章は入れていません。** 国旗と違って絵文字がなく、画像は権利関係が
  はっきりしないためです。日本編は「地図」と「漢字」の2本立てです。
- 東京都の県庁所在地は、中学の教科書に合わせて「東京」としています。
- 世界地図は**ミラー図法**で描いています。日付変更線をまたぐ国（ロシア、フィジー）も切れません。
  日本地図は元データがすでに平面座標なので、そのまま描いています。
