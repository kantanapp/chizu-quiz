# 世界地図クイズ

世界の**地図**と**国旗**から国名を当てる 4 択クイズです。中学の地理の勉強用に作りました。
インストール不要で、ブラウザだけで動きます（サーバーもビルドも不要）。

## できること

| | |
|---|---|
| **出題** | 地図から / 国旗から / ミックス |
| **地域** | 世界ぜんぶ / アジア / ヨーロッパ / アフリカ / 北アメリカ / 南アメリカ / オセアニア |
| **レベル** | 基本 70か国 / 標準 152か国 / すべて 194か国（国連加盟国） |
| **国名の表記** | 日本語 / English / 日本語＋英語 |
| **問題数** | 10問 / 20問 / 30問 |

- 地図は問題の国に合わせて自動でズームします。右下のボタンで **その国に寄る → 大州全体 → 世界地図** と切り替えられ、ドラッグとピンチでも拡大縮小できます。
- 陸地は一色にして、国の区切りは境界線だけで見せています。色がついているのは正解の国（オレンジ）だけなので、答える国の形がすぐ分かります。
- 小さすぎて見えない国には、位置を示す丸い印がつきます。
- 終わったあとに、まちがえた国の一覧が出ます。「まちがいだけ復習」でもう一度出題できます。
- ベスト記録は設定ごとに端末に保存されます（サーバーには何も送りません）。
- 「📖 国いちらんを見る」で、選んだ地域・レベルの国を国旗つきで一覧・検索できます。

## iPhone でアプリのように使う

1. Safari で公開ページを開く
2. 下の共有ボタン → **「ホーム画面に追加」**
3. ホーム画面のアイコンから起動すると、Safari のバーが出ない全画面表示になります

一度開けばオフラインでも遊べます（Service Worker がアプリ本体をキャッシュします）。

## GitHub Pages で公開する

このフォルダはリポジトリのどこに置いても、そのまま静的サイトとして動きます。

1. GitHub のリポジトリ → **Settings → Pages**
2. **Source** を `Deploy from a branch`、ブランチを `main` / フォルダを `/ (root)` にする
3. `https://<ユーザー名>.github.io/<リポジトリ名>/chizu-quiz/` で開けます

このアプリだけを独立したリポジトリで公開したい場合は、`chizu-quiz/` の中身をそのまま新しい
リポジトリの直下にコピーして Pages を有効にすれば、`https://<ユーザー名>.github.io/<リポジトリ名>/`
で開けます。

ローカルで確認するときは、このフォルダで簡易サーバーを立ててください
（`file://` で直接開いても動きますが、オフライン用のキャッシュは有効になりません）。

```sh
cd chizu-quiz
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル構成

```
chizu-quiz/
├── index.html                 画面の骨組み（3画面＋国いちらん）
├── css/style.css              見た目。ダークモード・iPhone のセーフエリア対応
├── js/
│   ├── map.js                 地図の描画（ミラー図法・SVG）と指での拡大縮小
│   ├── quiz.js                出題ロジック（画面には触らない）
│   └── app.js                 画面の組み立てと進行
├── data/
│   ├── countries.js           194か国の 日本語名 / 英語名 / 地域 / レベル  ← 自動生成
│   └── geo.js                 国境ポリゴン                                ← 自動生成
├── icons/                     PWA 用アイコン                              ← 自動生成
├── manifest.webmanifest       ホーム画面に追加したときの設定
├── sw.js                      オフライン用キャッシュ
└── tools/                     データとアイコンの生成スクリプト（公開には不要）
```

## データを作り直す

`data/` と `icons/` は生成物です。作り直すときだけ Node.js が必要です。

```sh
cd chizu-quiz/tools
npm install
node build-data.mjs    # data/countries.js, data/geo.js
node make-icons.mjs    # icons/*.png
```

### 出題する国やレベルを変えたいとき

`tools/build-data.mjs` の上のほうにある次の 3 か所を書き換えて、`node build-data.mjs` を実行します。

- `LEVEL1` … 「基本」で出題する国（ISO の 2 文字コード）
- `LEVEL2_EXTRA` … 「標準」で追加する国
- `JA_OVERRIDE` / `EN_OVERRIDE` … 国名の表記を教科書に合わせて上書きする

ファイルを更新したら、`sw.js` の先頭にある `CACHE` のバージョン
（`chizu-quiz-v1` → `chizu-quiz-v2` …）を上げてください。古いキャッシュが残らなくなります。

## 仕様のメモ

- **対象は国連加盟の 194 か国**です。地図データに形のない小さな島国（シンガポール、モルディブなど
  29 か国）は、地図の問題には出ませんが国旗の問題には出ます。
- **国旗は絵文字**（🇯🇵 など）で表示します。iPhone・iPad・Mac はそのままきれいに出ます。
  国旗の絵文字を持たない環境（Windows など）では自動で [flagcdn.com](https://flagcdn.com) の画像に
  切り替わります（このときだけネット接続が必要です）。
- 地図は**ミラー図法**で描いています。日付変更線をまたぐ国（ロシア、フィジー）も切れません。
