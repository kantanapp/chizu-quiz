# 地図クイズ

**世界の国**と**日本の都道府県**をおぼえるクイズです。中学の地理の勉強用に作りました。
インストール不要、ブラウザだけで動きます（サーバーもビルドも不要）。

### 漢字を書く問題

地図でオレンジ色の県を見て、その名前を指で書きます。**紙のマスに書くのと同じ**になるように
作ってあります。

- **マスは文字数ぶん横に並んだ、1枚の紙です。** どのマスにも、どの順番でも書けます。
  「愛知」なら愛を書き終えるのを待たずに、愛と知を続けて書けます。マスをまたぐ線も引けます。
- **書いた線は直しません。** 正解の形にすり替えたり、消したりしません。書いたものが
  そのまま画面に残ります。自分の字のまま最後まで書けます。
- **書き順は採点しません。** どの画から書いてもかまいません。
- 判定は **「✓ 答える」** を押したときだけです。そこで、書いた線ぜんぶと正解の形を
  突き合わせます。ちがっていれば、書いた線の下に正解の形を重ね、ちがった文字だけ
  色を変えて出します。どの文字がちがったかも出ます。
- 「↩ もどす」（1本消す）「🧹 ぜんぶ消す」「💡 ヒント」（お手本をひと目だけ見せる。
  お手本ありのときは出ません）。
- **なぞり書きと書き取りの違いは、薄いお手本が見えるかどうかだけです。**
  どちらも書いた線はそのまま残り、判定のしかたも同じです。
- **書いているあいだ、画面は動きません。** 指をすべらせても紙はスクロールせず、
  2本指や、とんとんと2回たたく操作でも拡大しません。画面がずれると、マスが指の下で
  動いてしまって字が書けなくなるためです。

判定のしかたと、ものさしの決め方は次のとおりです。

**画の本数も書き順も見ません。** 指で書くと2画をつなげたり、1画を2回に分けたりするのが
ふつうだからです。画を1本ずつ対応させると、正しく書いていても本数が合わないだけで不正解に
なってしまいます（お手本をなぞっても不正解になっていたのは、これが原因でした）。

見るのは次の4つです。

1. **なぞれている割合** … お手本の形のうち、書いた線が近くを通っている割合
2. **抜けた画** … 1画ずつ見て、ほとんど通っていない画の数。短い画をまるごと書き落としても
   気づけるように、割合の合計とは別に数えます
3. **はみ出している割合** … 書いた線のうち、お手本のどこからも遠い部分の割合。つなげ書きの
   渡りの線はここに出るだけで、なぞれている割合は落ちません
4. **書いた字が、101字のうちどれにいちばん似ているか** … 1〜3 だけでは「城」と「崎」、
   「野」と「崎」のような似た字を分けられません。書いた字と各漢字のへだたりを出し、
   答えの字がいちばん近い（か、わずかに劣るだけ）でなければ不正解にします

**4 は 1〜3 を上書きしません。** きれいになぞれている（なぞれ 0.97 以上・はみ出し 0.20 以下・
抜けた画なし）ときは、4 を見ずに正解にします。形が合っているという直接の証拠のほうが、
似ている順より確かだからです。お手本のとおりに書いてなぞれが 1.00 でも、別の漢字がほんの
わずかに勝ったせいで不正解になっていました（青森の「青」）。

1〜3 は、文字ごとに「どのくらいの大きさで、どこに書いたか」を割り出してお手本を寄せてから
測ります。**寄せるときの大きさは、たてとよこで別々に合わせます。** マスが正方形なので、
たて長の字を横に広げて書くくせが出るためです。**小さめ・右寄り・よこ長といった書きぐせは、
判定をゆるめるのではなく位置合わせのほうで吸収します。** 4 だけは、たてよこの比が
見分けの手がかりなので、そろえずに比べます。

ものさしは `node tools/check-kanji.mjs` の検証で決めました（`js/kanji.js` の `TOL` /
`COVER_MIN` / `STROKE_MIN` / `WEAK_RATIO` / `EXCESS_MAX` / `STRONG_COVER` / `STRONG_EXCESS` /
`MARGIN`）。手書きのブレを——つなげ書き・分け書き・よこ長・かたむきも混ぜて——作り、
数えた結果です。

| | ていねい | ふつう | ざつ | 別の県名を書いた | でたらめな線 |
|---|---|---|---|---|---|
| 2文字 | 100% | 95.3% | 76.7% | 1.5〜6.1% 通る | 4.7〜8.7% 通る |
| 3文字 | 100% | 100% | 84.4% | 0.0% 通る | 0.0〜3.1% 通る |

左の3列は「正しく書いて正解になった率」です。「ざつ」は 3割の画をつなげ、1割強を分けて書き、
形も大きくくずした場合です。**わざとでたらめな線を引いたときに通ってしまう率は、
正しく書いたのに不正解になる率より軽く見ています。** 自分で練習するための道具なので、
正しく書いたのに ✕ が出るほうが困るからです。

ものさしをさわるときは、同じスクリプトで測り直してください。

## 共通のしくみ

- 地図は問題の国・県に合わせて自動でズームします。右下のボタンで
  **寄って見る → 地方（大州）全体 → 全体** と切り替えられ、ドラッグとピンチでも拡大縮小できます。
- 陸地は一色にして、区切りは境界線だけで見せています。色がついているのは正解だけです。
- 小さすぎて見えないときは、位置を示す丸い印がつきます。
- 終わったあとに、まちがえたところの一覧が出ます。「まちがいだけ復習」でもう一度出題できます。
- ベスト記録は設定ごとに端末に保存されます（サーバーには何も送りません）。
- 「📖 いちらんを見る」で、選んだ範囲の国・県を一覧・検索できます。

## iPhone でアプリのように使う

1. Safari で公開ページを開く
2. 下の共有ボタン → **「ホーム画面に追加」**
3. ホーム画面のアイコンから起動すると、Safari のバーが出ない全画面表示になります

一度開けばオフラインでも遊べます（Service Worker がアプリ本体をキャッシュします）。

## GitHub Pages で公開する

ビルドは不要です。リポジトリをそのまま置くだけで動きます。

1. GitHub のリポジトリ → **Settings → Pages**
2. **Source** を `Deploy from a branch`、ブランチを `main` / フォルダを `/ (root)` にする
3. 数十秒待つと `https://kantanapp.github.io/chizu-quiz/` で開けます

## ローカルで確認する

`index.html` をブラウザで開くだけで動きます（`file://` でも動作します。

## データを作り直す

`data/` と `icons/` は生成物です。作り直すときだけ Node.js が必要です。

```sh
cd tools
npm install
npm run build        # 下の3つをまとめて実行
```

個別に走らせるときは次のとおりです。

```sh
node build-data.mjs    # data/countries.js, data/geo.js
node build-japan.mjs   # data/prefectures.js, data/japan-geo.js, data/kanji.js
node make-icons.mjs    # icons/*.png
```

漢字の判定のものさしを測り直すときは、次を実行します（生成物は作りません）。

```sh
node tools/check-kanji.mjs               # いまの設定で測る
node tools/check-kanji.mjs 55 65 75      # TOL の候補を並べて比べる
COVER=0.75 MARGIN=0.3 node tools/check-kanji.mjs   # ほかのものさしを振る
```

### 出題する国やレベルを変えたいとき

`tools/build-data.mjs` の上のほうにある次の 3 か所を書き換えて、`node build-data.mjs` を実行します。

- `LEVEL1` … 「基本」で出題する国（ISO の 2 文字コード）
- `LEVEL2_EXTRA` … 「標準」で追加する国
- `JA_OVERRIDE` / `EN_OVERRIDE` … 国名の表記を教科書に合わせて上書きする

都道府県名・よみ・県庁所在地は `tools/build-japan.mjs` の `PREFECTURES` の表にあります。

ファイルを更新したら、`sw.js` の先頭にある `CACHE` のバージョン
（`chizu-quiz-v4` → `chizu-quiz-v5` …）を上げてください。古いキャッシュが残らなくなります。

## 仕様のメモ

- 世界は**国連加盟の 194 か国**が対象です。地図データに形のない小さな島国
  （シンガポール、モルディブなど29か国）は、地図の問題には出ませんが国旗の問題には出ます。
- **国旗は絵文字**（🇯🇵 など）で表示します。iPhone・iPad・Mac はそのままきれいに出ます。
  国旗の絵文字を持たない環境（Windows など）では自動で [flagcdn.com](https://flagcdn.com) の画像に
  切り替わります（このときだけネット接続が必要です）。
- **都道府県に県旗・県章は入れていません。** 国旗と違って絵文字がなく、画像は権利関係が
  はっきりしないためです。日本編は「地図」と「漢字」の2本立てです。
- 東京都の県庁所在地は、中学の教科書に合わせて「東京」としています。
- 世界地図は**ミラー図法**で描いています。日付変更線をまたぐ国（ロシア、フィジー）も切れません。
  日本地図は元データがすでに平面座標なので、そのまま描いています。
